# 标签页身份、文章搜索与组图操作

## 本次范围

保留现有安静、无大块装饰的编辑风格；按作者新要求调整图片两侧导航，不重新设计画廊。使用项目风格与阅读/动效规范约束按钮、焦点、短动画和 reduced-motion。

### 访问角色与 favicon

- `getVisitProfile()` 为同一标签页会话选择角色，首页头像与 favicon 共用结果；允许重复抽到同一角色。刷新、站内跳转保留，sessionStorage 不可用时退回当前页面内存选择。浏览器恢复标签页也可能恢复该会话，不保证每次重开浏览器都更换。
- 7 套头像方案生成 32px / 48px PNG，共约 64 KiB，位于 `public/favicons/`。运行时选择 48px 图标（浏览器可缩小显示），32px 作为备用规格；不逐次访问 R2 下载头像来生成图标。
- `TabIdentity.astro` 在公共 Layout 加载；新图标加载成功后才统一替换 `rel="icon"`，加载失败保留原 favicon。Apple 主屏图标和静态 HTML 标题不变。
- 维护：`npm run assets:favicons -- --cdn` 从已配置公开头像下载生成；也可 `--source <本地 avatars 目录>`。生成只在维护命令运行，普通构建不访问 CDN。此次旧桌面头像目录不存在，因此采用公开 CDN；没有恢复桌面素材副本。

### 离开时祝福

- 根据 `visibilitychange` 更换标签页标题，提供中、日、西、法、英、德、意、葡、韩九种语言。
- 每次进入隐藏状态随机一次，不设置后台轮播、不闪烁。回来、页面恢复时恢复原文章/页面标题。
- 只检测自己的可见性，不读取访客打开了什么网页。隐藏也可能由窗口最小化、手机切换应用触发，不只限于访问其他网站。
- 文案集中在 `src/config/tabGreetings.ts`；不会更改文章 h1、URL、评论映射或静态 SEO 标题。

### 组图左右按钮与滚轮

- 两个箭头从底部操作组移到图片可视边界的左右中部，44px 点击区域；下载与关闭仍在图片底部右侧。单张图片不渲染箭头；组图首尾不循环，边界按钮禁用。
- 继续跟随图片尺寸，移出/闲置淡出，键盘焦点和触控保持可操作。没有把按钮固定在整个浏览器窗口边缘。
- 通过 PhotoSwipe 的 wheel 事件扩展：适应尺寸下滚轮下/右为下一张，上/左为上一张。50px 累积阈值；持续手势只切一次，停顿 220ms 后重新响应，防止触控板惯性跳过多张。
- 放大后仍由 PhotoSwipe 平移图片；Ctrl/捏合缩放、键盘左右和 Escape 保留。下载弹窗阻止 wheel 冒泡给图片查看器，本地列表可原生滚动。

### Blog 搜索

- 放大镜位于 Blog 大标题右侧；Category / Series 左右入口与对齐规则不变。栏目页复用相同入口，搜索范围是全部已发布文章。
- 点击打开原生 `dialog`，按需读取构建时生成的 `/blog/search-index.json`。当前索引约 60 KiB；同页再次打开复用内存，失败可关闭重试。没有数据库、搜索服务或额外 npm 包。
- 支持标题、正文、摘要、标签、分类名称和系列名称；中文连续词与空格分隔多关键词匹配，不区分大小写/重音；标题命中优先。不是拼音搜索、模糊纠错或语义搜索。
- 索引明确过滤 draft，使用现有文章链接；不保存、不上传搜索词。结果通过 DOM textContent 写入，不把搜索词或 Markdown 当 HTML 执行。
- 作者进一步审阅后收减为“输入框 + 标题 + 命中句”：移除可见面板标题、说明、分类、常驻结果数量、卡片边框与背景。对话框保留无障碍名称，加载/计数仅播报，失败和无结果时显示必要短提示。
- 摘要优先截取正文实际命中句，而非文章开头；短句完整保留，长句截取命中点周围上下文。关键词以月光蓝和细下划线高亮，不增加字重或改变文本几何；标签/系列单独命中时回退相应字段，仅标题命中则显示真实摘要，不重复标题或伪造命中句。高亮仍为安全的 DOM 文本节点，不注入 HTML。
- 搜索框上方锚定，结果区域预留固定视口内高度并独立滚动；结果更新只做 110ms 透明度过渡，不做高度动画，不推挤正文。中文输入法组词期间暂缓查询；增加上下箭头浏览结果。
- 输入聚焦、Enter 聚焦首个结果、Escape 关闭并回到放大镜；无结果/加载失败有播报。搜索框自带 Escape 清空行为被覆盖为关闭最上层搜索框。
- 180ms 入场、140ms 退场，快速关闭中断入场；reduced-motion 立即切换。局部滚动不交给 Lenis，不显示传统滚动条。没有 JavaScript 时隐藏搜索按钮，原文章列表与链接仍正常，可使用浏览器页面查找。

## 验证与边界

验收结果：`npm run check` 通过（类型零错误、64 项单元测试、79 个内容文档、22 页与静态搜索索引构建）；完整 Edge 回归 20 项通过。搜索输入前后位置偏差小于 1px，结果区域高度不变；桌面与 320px 窄屏截图已检查。

- 单元测试：滚轮阈值/归一化/惯性、中文与多关键词搜索、标题优先与本地图标尺寸。
- Edge 浏览器：搜索按需请求、重试、无结果、焦点恢复、320px 与 reduced-motion；图标会话一致、首页头像同步、存储失败降级；组图两侧位置、滚轮与下载框隔离、放大不切图。
- 可见性标题测试通过覆盖 visibility 状态触发事件验证，不冒充 OS 真实切换标签页；实际浏览器的书签/favicon 缓存和后台标题显示可能有各自策略。
- 原有文章稳定性、Category / Series 对齐、高清图/cover 与下载回归已一并通过；后续修改仍须保留这些检查。
- 图像点击回归还发现 PhotoSwipe 的 UI 可见样式覆盖了自定义 frame 的 `pointer-events: none`，使整层遮住图片缩放点击；已用限定于本站查看器的选择器恢复点击穿透，按钮仍独立响应。
