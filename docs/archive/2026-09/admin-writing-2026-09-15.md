# 2026-09-15：本地写作体验的核对与实施计划

第一版核心已经通过验收，见 [此前记录](admin-plan-2026-09-13.md#本轮验收记录)。本轮继续本地路线，优先解决文章仍需手写元数据、草稿只能查看源码这两个日常使用缺口。

## 调研与选择

仓库已有 `yaml` 的文档节点解析，以及 Astro 的 Markdown 处理器、数学公式插件。不新增另一套 CMS 或 Markdown 编辑格式。

- 元数据编辑读取 YAML 节点范围，只替换实际修改的值，保留正文、未知字段和无关源码。复杂锚点／标签等不能安全修改的节点要求回到源码处理。YAML 官方提供节点、源范围及注释支持；但直接整份 stringify 不能作为逐字保真的保证。[YAML 文档与节点 API](https://eemeli.org/yaml/#documents)
- 草稿预览放在没有脚本和同源权限的 sandbox iframe，并限制资源来源；原文 HTML 显示为代码，不执行。预览不会写文件、发布草稿或加载评论，公开网站的最终排版仍由 Astro 构建确认。[iframe sandbox 说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox)

## 本轮计划

1. 文章元数据读取与定点修改：标题、介绍、日期、标签、分类、系列／序号、草稿状态；保留自动推导和原文编辑入口。
2. 表单与源码只保留一份待保存内容；表单变更先应用到源码，实际保存仍使用原文件版本检查。切换或放弃修改要有提示。
3. 草稿正文预览：标题、段落、列表、引用、代码、表格、公式与允许的图片。原始 HTML、评论及其他交互不在预览中运行。
4. 验证无修改往返、注释／CRLF 保留、特殊字符、非法日期／系列、冲突、未保存预览以及脚本隔离；浏览器覆盖窄屏操作，再更新当前使用说明。

范围不包含在线身份认证、远程发布、删除／重命名、Git 恢复、R2 写入或配套头像创建。前述功能继续列入后续阶段，避免同时改动内容存储与发布架构。

## 实现结果与边界

文章信息表单已接入上述字段。先「应用字段到源码」，再保存文章；显示自动推导值，不自动把所有默认值填回文件。实际保存仍需 SHA 版本一致，分类与系列不匹配也会拒绝。表单读取后若原文继续变化，先保留双方输入并要求重新读取，不能用旧表单覆盖新原文。

后台加入独立正文预览：复用 Astro Markdown 和数学插件，保留标题去重规则；公式使用原生 MathML。原文 HTML 转为代码，链接不可导航，本地位图经过尺寸与格式限制后生成内存预览，外部图片仅允许既有 R2 域名。预览使用无权限 sandbox iframe 与 CSP，既不写文章文件，也不把草稿放进生产页面。

已保留常见标量、列表、多行文本之外的未知字段和正文；涉及锚点、自定义标签、列表内注释或带注释的复杂块值时，表单会拒绝该字段的定点更新，要求在源码处理。不会为了表单便利静默丢弃信息。

这仍不是生产页面的像素级预览：不运行评论、原文脚本、简谱生成、代码高亮及完整站点交互；最终排版继续通过构建核对。没有新增依赖、公开路由、云端授权或部署行为。

- `npm run check` 通过：150 个检查文件零错误／警告／提示，95 项单元测试通过，82 个内容文档零错误／警告，简谱有效，生成 26 个静态页面。
- 4 个后台浏览器场景通过：原有配置／冲突流程、移动端与键盘、文章表单及脚本隔离、源码变化后的表单保护。最后一个场景修正 textarea 断言后单独重跑通过。
- 修改字段的 YAML 注释、CRLF、BOM、多行值、未知字段与正文保留；拒绝非法日期、复杂锚点／列表注释及未知字段修改。预览未触发外域图片请求或执行原文脚本。
- 真实本地后台对 10 篇现有文章执行元数据读取、空修改往返和正文预览，全部通过，没有写入文章。
- 32 份开发／入口文档的相对链接无缺失，`git diff --check` 通过。最后的预览图片处理及提示调整另通过相关单元、浏览器和 TypeScript 检查。

改动仍在工作区，未提交或推送。本地后台入口为 `npm run admin`；最终排版和上线结果分别以生产构建与具体提交的 Actions 结果为准。
