## 已确认的产品规则

- 保留深蓝黑、低饱和、现有字体与星空。登录只需任务标题与表单；不默认使用「英文题签＋大标题＋中文宣传语」。画廊、书室让内容直接出现。首页作者指定的四组中英文入口名称保留。
- 公开登录入口只藏在首页头像中；普通账户使用 `/console/`，固定站主使用 `/telysta-console/`。后台采用完整视口、左侧分组导航、紧凑工具栏、右侧任务区，无账户空间 Hero。左上角品牌链接负责返回主页，不增加重复的 Back to site。
- 注册与登录分开：注册设置唯一用户名和密码，并验证邮箱；登录支持现有账户平稳迁移。不能用新增字段把已有站主锁在外面。
- 四级身份：普通用户浏览；正式用户管理自己的上传；超级用户拥有指定管理能力；固定站主 `weiser@telysta.com` 拥有最高权限。角色提升与限制内容授权仅站主操作，前端隐藏按钮不能代替后端授权。
- Session 保留为服务端实现，界面称「登录设备」。站主能撤销他人的登录，改密码、停用或权限变更必须处理旧登录状态。
- 成人漫画和明确指定的六四事件相关书籍受保护。站主及明确获授权用户可展示、下载和阅读；未授权者不得从接口、缓存、封面、搜索或 Range 请求绕过。
- 所有邮箱已验证账户可立即评论，不事前审核；每账户滚动一分钟最多 10 条。管理员可删除、隐藏和恢复，受保护书籍评论沿用相同访问权限。
- EPUB、MOBI、AZW3 使用网页阅读器，支持键盘和左右边缘翻页；保持封面比例、正文行宽和文字选择。PDF 在新标签页交给浏览器阅读，不另造重复工具栏。
- 书室桌面四列、加大封面、标题/作者/格式对齐；超长省略并可悬停查看完整文字。分类默认收起，按中图法与 Booklist 二次筛选。页码与前后页紧邻居中且直接可点击。
- 原始书籍、漫画、原字体不能因网站整理被删除。R2 资源按用途和文章归档；确认远端可用后才清理获授权的本地衍生图。
- DeepSeek Harness 参与边界明确的审查和文案等任务；主代理负责验证、鉴权、数据迁移与发布，不交出密钥或私有书库。

## 执行与发布原则

1. 先处理作者最新指出的重复导航，再完成账户认证基础；身份与权限稳定后接入后台表单、评论和 D1 发布。
2. 每项先核对现有代码与真实数据，再查官方文档；安全与复杂交互建立有意义的回归测试。界面同时核对桌面、手机、键盘和减少动态。
3. 迁移前备份；先在本地 D1/R2 替身中测试，测试不向真实用户发信。部署后只做必要的线上验证。
4. 角色、限制内容、所有权和评论限流在服务端执行。参数化查询、输出清理和不透明 Session 各自负责对应边界，不能互相替代。
5. 只提交已验收的明确文件及已批准的数据；保留作者同时修改的文章和待加入的书籍。密钥、私有完整书目、原书及临时报告留在 Git 之外。
6. Cloudflare Pages、账户 Worker、书库网关分别验证部署。保存草稿、构建完成和线上可见三个状态要准确区分。
7. DeepSeek 接受选定公开源码/文档的审查任务；采用建议前由主代理核对，鉴权、迁移和发布由主代理负责。

## 目标角色与能力

| 身份 | 数据角色 | 目标能力 |
| --- | --- | --- |
| 普通用户 | viewer | 浏览公开内容，邮箱已验证后可评论；不能上传或管理他人内容。 |
| 正式用户 | member | 普通能力，加上传与管理自己的内容；不因升为正式用户而自动获得限制内容权限。 |
| 超级用户 | superuser | 正式能力，加指定审核/评论管理；不能授予角色或限制内容访问。 |
| 固定站主（超级管理员） | admin | 全部管理能力及限制内容直通；仅绑定站主邮箱，不通过注册参数授予。 |

限制内容使用独立的逐用户授权。当前第一版授权范围是全部标记为受保护的馆藏，不按政治大类自动标记，也不把 Booklist 当作权限锁。授权的授予、撤销和审计由固定站主操作；撤销后新请求立即失效，前端同步收起私有内容。按书逐项授权与定时到期属于后续扩展，首版不宣称支持。
