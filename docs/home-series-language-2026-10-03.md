# 首页导航与系列语言修正

## 原因与计划

Navigation 使用 auto-fit，新增 About 后在宽屏排成三列，违背每行两项的要求。系列页显式读取英文元数据并标记 lang=en，导致已有中文标题与简介未用于主要阅读内容。

1. 保留作者在 home.ts 恢复的个人文案，不为搜索优化增加或改写首页段落。
2. Navigation 在大于 720px 时固定两列，多余入口顺序换行；720px 及以下保持单列。
3. 系列总览和详情的主标题、系列名称、文章标题与简介读取中文字段；页面 title、description 同步。移除错误的英语主区域语言声明，继承站点中文语言。
4. 保留 Series Archive、Series、Records 和 Manuscript 等英文题签与分类小标题。沿用现有留白、字体、色彩和动画。
5. 更新行为测试与当前文档，检查桌面、手机、断点和生产构建。

## 维护约定

- 首页作者文案由 src/config/pages/home.ts 维护；本次不修改该文件。
- 中文字段 title／description 是系列阅读默认值；英文 titleEn／descriptionEn 继续保留供其他用途，不删除元数据。
- 分类弹层花体角色名、英文分类入口与文章底部系列导航沿用现有规则。
- 历史文档的“系列全英文”描述是此前阶段记录，以本页及 feature-map.md 为当前规范。
