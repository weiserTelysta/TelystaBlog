## 非阻断发现

### P3：资源额外收录键缺少存在性校验

`tests/editor-config.test.ts` 的画廊测试把名单中的字符串直接作为模拟资源输入，只检查前缀、重复和发布保护，没有与真实资源条目及 CDN 清单交叉验证。若作者将一个键拼错，检查可能通过，但目标 Image 不会被收录。当前两个 Minecraft 键均有真实条目，现有页面不受影响。

建议后续在内容检查中验证每个 featuredImages 键能匹配资源，错误时指出具体配置项；不要让画廊自动公开 R2 全部图片作为回退。

### P3：分享浏览器测试仍固定默认图片 URL

`tests/browser/share-metadata.spec.ts` 将当前 Weiser 图片 URL 写死。作者按指南修改 `SITE_CONFIG.shareImage.url` 后，页面可以正常采用新图片，但这一断言仍期待旧地址，会造成浏览器回归误报。当前配置不受影响；CI 的 `npm run check` 不运行该浏览器测试。

建议后续让此断言从 SITE_CONFIG 读取默认地址，同时保留“静态 HTML 有且只有一个图片声明、地址为绝对 URL”的独立规则检查。
