# 搜索入口、Markdown About 与星空恢复修复

## 定位与实施顺序

1. 修复滚动结束后星点跳动，保留现有星空、配色、排版与原生滚动。
2. 核对服务器输出的页面标题、描述、canonical、分享信息与实际抓取入口。
3. 用 Markdown 建立 `/about/`，在首页 Navigation 区与 Resource Index 同级提供入口；补充首页可见的站点身份说明。
4. 补齐 robots、自动 sitemap 与 JSON-LD，验证无 JavaScript 可读性、移动布局和生产构建。

## 星空缺陷与修正

此前只是取消 requestAnimationFrame，星点的漂移、闪烁等仍以浏览器绝对时间计算，因此恢复绘制时跳到了暂停之后的位置。原有测试只证明“暂停／恢复绘制”，没有检查恢复的位置连续性。

现在 `animationClock.ts` 统一管理实际绘制时间。恢复首帧沿用暂停时刻，后续才继续推进；星点、流星、心形与点击粒子使用同一时间基准，隐藏页面、模态层及动态偏好切换也重置帧间计时。保留上一轮 30fps 绘制上限、渐变缓存和原生滚动。

移动浏览器地址栏改变视口高度时，画布调整尺寸，但不再随机重新生成整片星点。新增单元与浏览器测试直接比较暂停前和恢复首帧的星点坐标。

## 当前搜索与身份能力

| 项目 | 实现与维护位置 |
| --- | --- |
| 首页身份 | `src/config/pages/home.ts` 的既有简介新增一句站点定位；随机角色头像与欢迎语保留原样 |
| About | 直接编辑 `src/pages/about.md` 的 title、description 和 Markdown 正文；`MarkdownPage.astro` 沿用共享 prose 与文章标题样式，不进入博客时间线 |
| 入口 | 首页 Navigation 与 Resource Index、Telysta Annals 同级；保留原有顶部导航布局 |
| robots | `src/pages/robots.txt.ts` 构建为 `/robots.txt`，允许抓取并声明 sitemap，站点域名取自 Astro 配置 |
| sitemap | 官方 `@astrojs/sitemap` 按实际生成页面自动构建 `/sitemap-index.xml`、`/sitemap-0.xml`；排除搜索 JSON；草稿不生成文章路由，因此不进入 sitemap |
| canonical | 沿用每页 ShareMetadata，忽略查询参数并统一尾斜杠，与静态目录地址及 sitemap 一致；路由仍接受原有无尾斜杠链接，不强制拒绝旧入口 |
| JSON-LD | `structuredData.ts` 与 ShareMetadata 输出 WebSite、Person、WebPage／CollectionPage／AboutPage；文章另含 BlogPosting，标题、日期与标签取自真实文章数据 |
| 无 JS 阅读 | About、博客正文及元信息均静态输出；首页提供无 JS 标题与简介，解除原先依赖 IntersectionObserver 才可见的介绍／路标 |

JSON-LD 使用实际站名 Weiser's Melancholy 与作者 Weiser，不把 Telysta 角色误标为站主，不虚构机构或认证。嵌入 JSON 会转义 `<`，防止内容中的脚本结束符破坏页面。

项目与开发记录已由 `/blog/category/manuscript/` 承载，About 明确链接到这里；本轮不新建重复或空的 `/projects/`。以后有独立项目介绍、仓库、演示和维护状态时，再建立项目目录。没有添加关键词堆砌、自动翻译、虚构语言版本或 AI 专用隐藏内容。

## 发布后维护与边界

- 搜索平台可提交 `https://telysta.com/sitemap-index.xml`。Google Search Console／Bing Webmaster 的站点验证与索引请求仍需在对应账号完成；代码部署不等于保证收录或排名。
- robots 是抓取规则，不是访问控制，也不代表所有 AI 服务一定会读取网站。Cloudflare 若启用机器人挑战、托管 robots 或特定 AI 阻挡，需要在控制台独立核查；本轮不改变边缘访问策略。
- `llms.txt` 尚不是 Google AI 搜索所要求的文件。当前优先维护可见正文、真实链接和一致的机器元信息；不承诺 AI 引用效果。
- sitemap 不统一写“当前构建时间”为 lastmod，避免把部署当作内容修改。
- 本轮依赖审计发现既有开发依赖 fast-uri 3.1.7 的中危公告，定点更新为 3.1.8，安装后审计为 0 项漏洞；未执行整库升级。
