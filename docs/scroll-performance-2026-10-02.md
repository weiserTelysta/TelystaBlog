# 滚动性能、目录小写与文档整理

后续修正：本轮最初仅暂停绘制，恢复时仍按绝对时间计算星点位置，造成跳动。已改为独立动画时间并补充坐标连续性回归；当前行为以 [修复记录](seo-about-2026-10-02.md) 为准。

## 定位与计划

1. 核对 `Notes` 的目录、路由和引用，使用 Git 两步更名为 `notes`，保留文章内容与 URL。
2. 在桌面及触摸模拟环境采集列表、资源与长文章的滚动响应和动画开销，区分输入缓动与背景绘制。
3. 统一原生滚动，减少阅读期间的装饰开销；验证目录、进度条、回顶、弹窗与减少动态设置。
4. 将已完成的阶段文档归档，更新当前规范与链接，执行类型、构建及浏览器回归。

## 发现与修改

- 旧配置在博客列表和资源页启用 Lenis 滚轮插值，`wheelMultiplier: 1.02`。600px 输入在 100ms 时只到约 368–378px，约 600ms 后才到 610px；文章页已经使用原生滚轮，约 100ms 即到 600px。
- 手机 `syncTouch` 原本关闭，不能把手机问题归因于触摸插值。原实现仍创建 Lenis 常驻动画循环；星空按屏幕刷新频率重绘，每帧新建全屏渐变，窗口高度变化立即重建画布。一次模拟采样每秒创建 111–167 次渐变。
- 移除 Lenis 依赖、ScrollManager island 和对应样式。滚轮、触摸及局部滚动由浏览器处理；目录与回顶使用原生平滑导航，减少动态或拖动进度条时立即定位。对话框使用可嵌套的页面滚动锁。
- 星空保留原色彩、星点分布和交互；绘制上限 30fps，静态渐变只在尺寸改变时创建，触摸设备 DPR 上限为 1.5。滚动期间保留最后一帧，停止 150ms 后恢复；尺寸变化合并 160ms 后处理；隐藏页面、模态层、减少动态继续暂停，系统偏好变化即时生效。
- 进度条位置通过 ref 更新样式和辅助属性，避免每个滚动帧触发 React 渲染。拖动直接定位；回顶按钮的水平避让仅在尺寸改变时重新测量。
- `legacyPostId()` 已将各段路径统一转小写，四篇 Notes 文章更名后保留原有 `/blog/notes/.../` URL 和 pathname 评论映射。英文界面题签 `Notes` 不属于文件夹命名问题，保持原样。

实现参考：[Lenis 官方配置](https://github.com/darkroomengineering/lenis)、[MDN Canvas 优化](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)。

## 文档整理

11 份已完成的阶段记录移入 `archive/2026-09/`，补充月度索引；文档首页区分日常规范、当前专题、待实施方案与历史记录。同步更新架构、功能表和当前状态中的滚动及 PSD 说明。未实施的云端后台、多语言方案仍保留明确入口。

## 验证与边界

- `npm run check`：Astro 类型检查 0 错误／0 警告，112 项单元测试通过，生产构建生成 34 页。
- 浏览器回归：原有 54 项通过，新增 5 项滚动测试通过（桌面博客／资源滚轮、手机触摸、背景暂停及动态偏好切换、进度条拖动与键盘）。首轮新增测试误将桌面进度条用于手机断言，已按真实显示范围拆分后通过。
- 四篇笔记对照 Git 原稿，除工作区换行符归一化外内容一致；生成页面存在，大小写迁移前后的文章 ID 相同。文档相对链接目标检查通过，桌面画廊及手机文章截图未见布局回归。
- 同样 600px 桌面滚轮输入，优化后博客、资源和文章均在 100ms 采样点到达 600px，随后不再追加缓动；没有取消滚轮默认事件。
- 六组页面／设备模拟采样中，空闲 1 秒内动画回调总耗时由约 65.6–113.8ms 降至 19.7–29.2ms；静态渐变创建由每秒 111–167 次降至 0 次。连续滚动暂停绘制、停止后恢复由独立回归验证。测量脚本与原始记录保存在本地 `.tmp/scroll-2026-10-02/`，不随站点部署。

性能采样来自本机 Edge 桌面／触摸模拟，受机器负载与采样时序影响；它说明工作量减少，不等同于真实 iPhone、Android 或 Safari 的帧率结论。真实设备仍需复核手感。
