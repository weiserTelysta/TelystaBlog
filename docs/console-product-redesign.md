# 线上工作台产品化

2026-11-15，按作者提供的 Cloudflare 管理台参考实施。

## 问题与方向

旧后台把文章页的容器、标题和留白套用到管理界面，又把数据库记录、文件名和源代码直接交给使用者。统一颜色和字号没有解决操作结构。

新界面使用完整视口、固定分组侧栏与紧凑工具栏。取消账户空间大标题、装饰性英文题签与重复身份介绍。右侧直接进入列表、表单、编辑与预览。公开网站保留原有艺术风格；后台使用操作界面的密度和布局。

## 工作流程

- 内容：文章正文与分类／系列分开编辑；书籍使用作者、封面、中图分类、附件与访问范围表单；画廊使用作品、图片、署名与许可表单。
- 设置：按用途解释站点身份、首页导航、阅读、画廊和交互选项；保留函数、导入和未知字段；高级实现细节按需展开。
- 账户：登录设备替代Session术语，展示设备、时间、当前设备和退出操作。角色授予、限制内容授权仅固定超级管理员可修改。
- 社区：邮箱已验证账户均可评论，每账户每分钟最多10条；无需事前审核。后台可处理评论，受保护线程执行相同访问限制。旧GitHub评论保留历史入口。
- 备份：选择要备份的内容，显示范围与结果，不把存储实现当作主操作。
- 全部界面支持中文和英文，切换保留当前上下文与未保存输入。

保存云端草稿仍不等于公开部署；操作反馈必须准确，不得虚构发布成功。
