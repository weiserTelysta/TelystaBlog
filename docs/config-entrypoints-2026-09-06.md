# 作者配置入口整理

本轮为行为保持重构，遵守项目设计守则，不修改 CSS、文案内容、动画时长、滚轮算法或键盘操作。上一轮分享元信息改动继续保留。

## 变更

- 搜索、系列索引文案接入 `pages/blog.ts`；看图与下载接入 `pages/resources.ts`；代码复制状态接入 `pages/article.ts`。
- 下载选择模板中的可编辑文字使用 textContent / setAttribute，不把配置拼进 innerHTML。
- 分类弹窗 DOM ID 移回组件，不再和作者文案混在一起。
- 分类与系列从唯一资料数组派生 ID 和精确联合类型；保留原导出名、顺序、ID、路由及 Schema 调用。
- 非插画 Image 收录名单移至 `content/resourceGallery.ts`，草稿与敏感资源类型排除仍由 lib 强制执行。
- 配置测试检查唯一 ID、有效关联、权重、时间偏好、非空文字与占位符。祝福条数不再锁死为 9；停用头像不再要求生成其 favicon。
- 搜索及看图的交互测试从配置读取按钮名和提示，修改措辞不会仅因旧断言文字而失败。
- 新增 [配置编辑入口](../src/config/README.md)，包含常用路径、例子、限制、生成步骤和发布方式。

## 范围边界

这不是可视化后台或整站多语言框架；不把所有常量暴露为设置。Giscus 集成参数、算法常量与样式 token 保留原所有者。分类视觉映射仍单独维护，新增分类时类型检查会指出遗漏。

## 验证

修改前保存桌面与 320px 搜索基线到 `.tmp/config-before/`，不提交临时截图。构建、内容校验与完整浏览器回归用于确认输出及交互保持一致。

验收：`npm run check` 通过（类型零错误、70 项单元测试、79 份内容文档、22 页构建），完整浏览器回归 21 项通过。已复核桌面与窄屏搜索截图，未发现本轮引入的视觉变化。

回归期间发现旧滚轮测试在两次事件之间等待断言，繁忙机器上可能超过 220ms 手势窗口；单独复测通过。测试改为在一个浏览器任务内派发连续 WheelEvent，确定性验证惯性隔离；真实鼠标滚轮的放大平移检查仍保留，网站滚轮实现未改动。
