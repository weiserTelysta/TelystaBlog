# Telysta 花卉装饰

## 从现有构图出发

- 先看目标组件的桌面与手机实图，找到文字框、阅读方向和可以容纳花卉的留白。优先复用 [花卉素材](../../../src/assets/images/decorations/) 与现有组件。
- 首页的范例在 [HomeSection.astro](../../../src/components/home/HomeSection.astro)、[HomeFlowerTrail.astro](../../../src/components/home/HomeFlowerTrail.astro) 和 [HomeArchive.scss](../../../src/components/home/HomeArchive.scss)。右边的主花定义重心，左边以碎瓣、小花和空隙过渡。现有每组约十片细节只是这个入口尺寸的参考。
- 作者认可的节奏来自错落与停顿。靠近主花的小簇更完整，向文字方向逐渐变小、变淡、拉开间距。让一两片淡瓣到达文字下层或底边，维持字形轮廓和点击范围。用位置、朝向和大小体现流势，避免碎瓣分成上下两排或使用可见长线。
- 用花的特征决定小簇形状。樱花用缺口瓣和疏散的落点，桃花用暖色瓣和花蕊，山茶用卷瓣和重瓣，绣球用四瓣小花成簇。同页各用自己的节奏与配色。

## 区分调整构图与细修花瓣

用户认可疏密后，优先保留现有落点、数量、尺寸和主花位置。在 SVG 形状定义内加薄的明暗渐层、花瓣折面和少量花蕊。放大的细节也要在实际尺寸和高像素密度屏幕上看一次，选择能读出质感的细节。

小碎瓣和微型花朵可使用 [首页 SVG 组件](../../../src/components/home/HomeFlowerTrail.astro) 的局部定义与复用方式。对于百合、丝带等有水彩边缘和多层细节的透明插画，参考[百合与缎带制作记录](../../../docs/lily-and-ribbon-workflow.md)中的实际生成调用和 WebP 导出流程。

## 动效与验证

- 先让主花与碎瓣以静态构图成立。首页路标悬停或键盘聚焦时，主花绕花心短旋，各瓣从根部错时舒展。附近的小花与碎瓣从近到远轻轻呼应。把最疏的一段留在原位，维持文字下方的留白和链接的位置。
- 将可动部位标在现有 SVG 上，内联时为局部 ID 加上组件前缀。惯用缓动来自项目 token，退场取消错时并较快收拢，便于光标快速经过几个入口。减少动态时立即呈现亮度反馈。有独立图片的场景可以只调其图层亮度。
- 将装饰放在文字下层，使用 `aria-hidden` 或空 `alt`，并让它透过点击。桌面、手机、键盘聚焦与减少动态都要检查。首页导航的现有浏览器检查在 [home-navigation.spec.ts](../../../tests/browser/home-navigation.spec.ts)。
