# 中图法与书单映射

## 归类规则

沿用中国图书馆分类法（CLC）的学科分类，与读者年龄／公开发现方式分开。基本大类与参考名称见[复旦大学图书馆中图法简表](https://library.fudan.edu.cn/xszl/e8/ae/c42129a518318/page.htm)。分类以书籍内容和可靠书目为依据，不用国家、作者国籍或文件格式直接代替学科判断。

- `clcCode` 保存实际细分类号，`clcName` 保存该类名称；网站 `src/content/ebooks/catalog/_classes.json` 的大类名称是导航缩写，不是另一套分类法。
- 根书架平铺普通书籍；`/ebooks/clc/K/` 等大类页面列出其 Booklists 和普通条目；细分书单 `/ebooks/booklists/K351/` 对应印度分类。页码、搜索和格式筛选保持当前书单范围。
- Booklist 按 `clcCode` 精确分组，大类按首字母映射。含 `/` 的范围类号用于单段URL时转为 `-`，如 `F13/17` → `F13-17`；数据保留原类号，生成器检查slug碰撞，不能把范围码物理拆成另一学科。
- `categoryOnly: true` 是仅书单展示标记，不改变CLC；总览及大类列表／搜索排除，进入该细分类书单后显示。书单的父级预览不选用这类条目的封面。
- 已有 D73/77、E3/7、F13/17、I3/7 等目录因Windows路径里的斜杠体现为多层目录；保留原始相对路径与实际R2 key的对应，不自行扁平化旧对象。
- 同一类号历史标签可能有别名，例如C912、C913、J1、TQ65；新增时核对内容及可靠书目，避免仅因目录标签差异重传。曾把射频实验手册从TP3校正为TN，仅修正书目，不改既有文件／对象路径。
- 新书可以引入新细类；不必改路由代码。需要修改基本大类导航时才更新 `src/content/ebooks/catalog/_classes.json`。新增映射后更新分类登记表，不把某一批次的细类数量视作永久白名单。

## 维护类号和书单

当前类号、显示名、明确接受的别名与来源统一登记在仓库 `data/library/clc-mappings.json`。该文件是维护入口，不再把某一批次的细类数量或旧 CSV 当作固定白名单。网页书籍仍保存于 `src/content/ebooks/catalog/<大类>.json` 的 `booklists`，以书单 `clcCode`／`clcName` 为准。

- 新建细类前核对书内题名、版权页／CIP、目录与馆藏记录；再更新登记表和对应分类JSON。`npm run content:check` 校验登记、类号与类名是否匹配。
- `reference-checked` 表示类号及本批文献内容经过对照，不等于每一册CIP都已逐字核实；`legacy-label` 表示保留的历史映射，仍待逐书复查。不能把存量标签批量改成“已核实”。
- 类名别称放入 `aliases`，不要给同一类号建立多个不同主题的书单。发现语义错误应纠正，不能借别名绕过：例如 H711 是**古印度语**，H71 才是印度语族；H712 是印地语，不能将整个语族都放入 H711。
- 小说写作指南属于文学创作，剧本写作属于电影／戏剧文学创作，不因中文译本而统一归入 H152。神话作品集与神话研究、游戏小说与游戏设计、心理学读物与临床精神治疗要区分。
- 保留书内可靠的细分类号；不要为排版统一降为大类，也不要把“二次筛选”理解为所有类号都必须两位长。证据不足时使用已核实的上级类，并在批次证据中记录待复核原因。
- 将书内CIP与初步分类交叉比较，跨前缀差异不能静默丢弃。本批曾发现《人论》G02、《波斯神话》B932和《中世纪与文艺复兴》K503；另有旧CIP与现行馆藏不同的游戏设计、文化人类学资料。公开证据以`printedCipCodes`、`classificationResolution`和`classificationReviewNote`记录采纳或保留差异的理由，不把同前缀匹配数量冒称全面复核。
- 网站分类调整不改固定ID，也不自动移动原书或已有R2对象。文件链接始终使用实际对象Key。

## 分类证据和旧批次

公开批次证据保存于 `data/library/ingest-<日期>.json`，记录固定ID、完整文件SHA-256、类号／类名、核对方式、来源和稳定对象Key。原始路径、书籍正文、OCR输出及受保护书籍的完整证据留在 `.tmp/` 或 `.library-private/`，不提交公开Git。

历史新增例子可查 `data/library/ingest-2026-11-14.json`：D731.361 日本阶级／阶层、F131.26 韩国经济、F823.130 日本货币政策和 K543 南斯拉夫。它们是既有书目证据，不是新批次授权名单，也不代表其他书应自动套用相同分类。

基础参照：[广东石油化工学院图书馆分类表](https://lib.gdupt.edu.cn/xszl/zhongtufa/h.html)、[图书馆分类详表的公开对照副本](https://publishmedia.cbpt.cnki.net/portal/minio/webs/fhlx/media/web/2025/07/09/%E4%B8%AD%E5%9B%BE%E5%88%86%E7%B1%BB%E5%8F%B7.pdf)。部分网页介绍的是第四版，使用时必须结合当前CIP／馆藏复核，不把旧表冒称第五版全文。
