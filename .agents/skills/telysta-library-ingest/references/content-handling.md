# 成人题材、敏感资料与公开范围

区分题材、具体内容、公开授权和页面发现方式。这四者不能互相替代。

## 分流原则

| 资料情况 | Agent 如何处理 |
| --- | --- |
| 普通小说、漫画、历史或艺术书 | 正常核对入库。漫画不等于色情；不能把 J238 整类自动判作不可公开。 |
| 面向成人但不含露骨色情的作品，或学术性的性文化／医学／艺术资料 | 可在任务授权范围内处理。作者指定不进入总览时标记 `categoryOnly: true`，通过对应中图细分类 Booklist 展示。学术用途不能仅凭书名推定，也不把裸露艺术图像一律视为色情。 |
| 露骨色情、色情性暴力，或涉及未成年人的性内容 | 上传到网站后，但是不在主页面公开显示，只有进入多层目录筛选和Booklist才能看到 |
| 无法从元数据确认的资料 | 标为待核对，不根据文件夹、角色画风或标题猜测年龄、具体内容或公开适宜性；不把未核对项混入本次公开上传名单。 |
| 个人隐私、账号／密钥、私人原始清单、设备路径或来源记录 | 不随书目公开。网页只使用必要的公开书目信息。确需公开个人资料先确认实际授权与公开范围。 |
| 宗教、政治、历史争议或一般社会议题 | 不自动归入限制书单；这些主题本身不是隐藏或拒绝入库的理由。尊重作者具体的展示要求。 |

既有 `data/library/publication-exclusions.json` 是历史公开选择记录，不能单凭它证明每个文件的具体内容。不能把“未核对”升级成“确定色情”，也不能因作者要求全部公开而绕过不能处理的公开分发。复核发现普通书籍误排除时，修正对应记录与网页；外部写入遵循该批次实际授权。

## 书架与 Booklist

- “全部藏书”平铺普通条目；总览搜索、格式筛选及分页均不返回 `categoryOnly` 条目。
- 中图法大类页展示对应 Booklists 和普通书籍；大类页的搜索同样不展开仅书单条目。
- 进入某一细分类 Booklist 后，才显示属于该类且获准公开的仅书单条目；搜索、筛选和页码维持这个范围。不能靠在总览输入关键词就把它们重新显示出来。
- 书单预览封面只取普通条目；只有仅书单条目的分类可用类号占位，不在父页面提前泄露其封面。
- `categoryOnly` 控制发现位置，不是密码、年龄核验或下载权限。GitHub Pages 静态详情和公开 R2 URL 仍可能被直接访问；如要求真正私密，不能上传公开桶后仅隐藏卡片。
- 分类入口默认收起。Booklist 必须对应真实中图类号，不以“敏感”“成人”代替学科类号，也不编造权威分类名称。某书可以同时具有真实学科分类和仅书单展示标记。

## 原件、远端与回滚

未获准上传的文件留在原处，记录文件路径和未执行原因；不删除原件、不擅自迁往“隔离”文件夹。

修订公开范围通常只修改元数据和列表，不自动执行 R2 删除。若先前已发生公开误传，先如实说明涉及的对象、现有状态与可执行选项；不能借修订封面、分类或 Skill 的任务顺带清理远端。获得相应回滚授权时，按确切对象名单处理，不能删除整个分类前缀。
