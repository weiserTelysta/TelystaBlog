## Giscus
Giscus 是一个建立在 GitHub Discussions 之上的评论系统。

它自己并不负责替我保存一套独立的评论数据库。Giscus 做的事情，是把 GitHub Discussions 中的内容嵌入我的文章页面。于是从访客的角度来看，文章下面出现了一个正常的评论区。

使用起来只需要新建一个空白的仓库，还是非常方便的。
